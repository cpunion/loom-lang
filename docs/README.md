# Loom documentation

Goals, implementation, and delivery are different layers:

- [Project charter](project/charter.md): user goals and responsibility boundaries.
- [Language foundation](rfcs/language-foundation.md): accepted language decisions.
- [Changes and deployment](rfcs/change-and-deployment.md): accepted evolution
  and recovery workflows.
- [Design records](rfcs/README.md): status and authority of those decisions.
- [Roadmap](../ROADMAP.md): native implementation and early self-hosting gates.
- [Implementation status](project/implementation-status.md): current evidence.
- [Compiler guide](../compiler/README.md): build, test, run, and present limits.

The former versioned references described a removed implementation and are no
longer a parallel specification. Consult Git history when auditing that work,
not as evidence that the current compiler supports a feature.

Repository process is in [Contributing](../CONTRIBUTING.md);
user-visible changes are in the [changelog](../CHANGELOG.md).
