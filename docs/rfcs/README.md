# Design records

Acceptance fixes the target, not current feature availability. The compiler
guide and executable tests describe current implementation evidence.

## Accepted direction

- [Language foundation](language-foundation.md)
- [Changes, library evolution, and deployment](change-and-deployment.md)

These records govern the [roadmap](../../ROADMAP.md). The former typed-codegen
proposal described the removed compiler and is not an architecture requirement
for its replacement.

New decisions state the problem, observable semantics, boundaries, and a small
acceptance story. Keep unresolved choices explicit instead of presenting them
as implemented or adding a second specification.
